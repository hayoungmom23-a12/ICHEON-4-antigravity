## 1 공통 스타일 가이드

- 확정된 무드: **A. 화이트 체크카드 + 채움 버튼 + 진초록 히어로** (2026-09-18 갱신). 흰 카드, 얇은 테두리, 짙은 청록 강조색 하나, 줄 끝의 바깥 링크와 큰 버튼은 청록으로 채운 둥근 박스. 페이지 바탕은 흰색이고, 코스 목록 맨 위에만 진초록 회색 그라데이션 히어로 블록(서비스 이름 + 한 줄)을 둔다. 2026-09-16에 정했던 연한 미색 바탕(`#FAF7F0`)은 Claude Design 시안을 기준으로 삼으면서 흰색으로 바꿨다. 미색으로 되돌리려면 5절의 `--bg` 값 하나만 바꾼다.

- 버튼 (확정): 줄 끝의 바깥 링크 "네이버지도에서 열기", "공식 페이지", "네이버플레이스"는 밑줄 글자가 아니라 짙은 청록 `#0F6E56` 채움 + 흰 글자 + 8px 둥근 박스이며 높이 40px 안팎(줄 전체 높이는 44px 이상). 식당 부록의 "근처 식당 네이버지도에서 보기"는 같은 채움에 10px 모서리, 높이 48px, 카드 폭 전체. "← 코스 목록"처럼 화면 안에서 이동하는 링크만 글자 링크로 둔다.

## 3 화면별 프롬프트 블록 (Google Stitch 붙여넣기용)

각 블록은 그 자체로 완결된다. Stitch는 이전 블록을 기억하지 못하므로 "스타일" 줄을 매 블록에 반복했다. 스타일 줄은 확정 무드(A + 크림 바탕) 기준이다. 카드 안 예시 문구는 모양을 잡기 위한 것이며 실제 운영 정보는 구현 단계에서 데이터 파일로 넣는다.

### 상태 규칙

- 사진이 없는 스팟: 사진 자리는 `--photo`로 두고 구역을 지우지 않는다.
- 팁이 없는 스팟: 방문 팁 버튼과 구역을 숨긴다(덕평공룡수목원).
- 약도·숙박이 없는 스팟: 해당 버튼과 구역을 숨긴다.
- 공식 페이지가 없는 시설: `map` → "지도 열기", `phone`만 있으면 "전화", 둘 다 없으면 버튼 없음.
- `official`이 `[`로 시작하면 자리표시이므로 링크로 쓰지 않는다.
- 취향 칩: 켜진 칩을 다시 누르면 꺼지고 5장 전체로 돌아온다.
- 코스를 새로 열면 스팟 펼침·더보기 상태는 모두 닫힌다.
- 모든 바깥 링크는 새 창(`target="_blank" rel="noopener"`).
- PC(폭 640 초과): 같은 컴포넌트를 폭 640 가운데 기둥에 그대로 쓴다. 격자 배치 없음.
