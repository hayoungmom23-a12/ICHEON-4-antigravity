# 이천 아이맵 결과보고회 발표 구성안

상태: 완료

## 발표 한 줄 소개

이천 나들이를 위한 콤팩트 가이드. 자세한 정보를 찾기 전에 훑어보는 메뉴판 같은 페이지입니다.

## 1. 누구를 위한 페이지인가

미취학·초등 저학년 아동과 함께 가족 나들이를 하는 사람을 위한 페이지입니다.

## 2. 어떤 문제를 풀고자 했나

체험·식사 등 나들이 정보가 여러 곳에 흩어져 있어 각각 찾아봐야 합니다. 동반 아동의 연령까지 고려해 정보를 모으고 일정을 잡기 어렵습니다.

## 3. 이천의 매력

쌀과 먹거리, 자연과 공원, 아이가 즐길 체험, 수도권에서의 접근성을 함께 보여줍니다.

## 4. 어떤 페이지를 만들었나

이천 아이맵은 이천 나들이의 선택지를 빠르게 훑어보는 모바일 웹페이지입니다. 현재 결과물에는 취향별 코스 5개, 코스별 장소 소개, 주차·진입 안내, 시설 운영 정보, 방문 팁과 식당 링크가 있습니다.

## 5. 결과물에서 보여줄 장면

주차·진입 안내, 스팟 약도의 경로 표시, 직접 방문하며 얻은 팁을 보여줍니다. 일반 방문자 화면에서는 사진 편집 버튼을 숨기고, 배포 주소에 `?edit=true`를 붙이면 편집 화면을 확인할 수 있습니다. 사진의 영구 저장과 GitHub 반영 버튼은 로컬 미리보기 서버에서 활성화됩니다. GitHub와 연결된 Vercel 배포라면 반영 뒤 사이트가 다시 배포됩니다.

## 6. 보완이 필요한 점

기획서를 여러 번 고치면서 일정이 늦어졌습니다. 다음에는 핵심 기능의 초안을 먼저 만들어 사용해 보고 기획서를 다듬는 방식을 시도하고 싶습니다. 유지관리를 위한 기능을 만드는 데 시간을 많이 써서, 실제 콘텐츠를 더 채우거나 새로운 콘텐츠 구현 방식을 시도할 시간이 부족했습니다.

## 7. 향후 활용·확장 계획

웹페이지를 기획하고 직접 만들어 본 경험을 실제 사업에 활용하고 싶습니다. 아임웹이나 카페24 같은 플랫폼과 직접 코딩한 페이지를 결합해 홈페이지를 만들어 보고 싶습니다.
