## 1 공통 스타일 가이드

- 확정된 무드: **A. 화이트 체크카드 + 채움 버튼 + 진초록 히어로** (2026-09-18 갱신). 흰 카드, 얇은 테두리, 짙은 청록 강조색 하나, 줄 끝의 바깥 링크와 큰 버튼은 청록으로 채운 둥근 박스. 페이지 바탕은 흰색이고, 코스 목록 맨 위에만 진초록 회색 그라데이션 히어로 블록(서비스 이름 + 한 줄)을 둔다. 2026-09-16에 정했던 연한 미색 바탕(`#FAF7F0`)은 Claude Design 시안을 기준으로 삼으면서 흰색으로 바꿨다. 미색으로 되돌리려면 5절의 `--bg` 값 하나만 바꾼다.
- 주 사용 기기: **모바일 우선**. 기준 폭 390px, 한 열 배치. PC에서는 최대 폭 약 640px의 가운데 기둥으로 보여주고 좌우는 빈 배경으로 둔다. PC 전용 격자 배치는 만들지 않는다.
- 컬러 방향 (확정, 2026-09-18 갱신): 바탕 흰색 `#FFFFFF`, 카드 흰색 `#FFFFFF` + 따뜻한 회색 테두리 `#E6E0D4`, 카드 안 구분선 `#EEEAE2`, 사진 자리 `#F1EDE4`. 히어로 블록은 `#354E49`에서 `#273A36`으로 내려가는 세로 그라데이션에 흰 글자(시안 PNG 표본값). 그라데이션은 이 블록 한 곳에만 쓴다. 본문 글자 `#1F2933`, 보조 글자 `#5C6470`. 강조색은 짙은 청록 `#0F6E56` 하나이며 옅은 청록 `#E1F5EE`를 배경 띠로 짝지어 쓴다. 강조색은 링크, 켜진 칩, 추천 주차장 띠, 방문 팁 배지에만 쓴다. 취향 트랙 칩은 만들기 `#FAEEDA`/`#633806`, 야외 활동 `#EAF3DE`/`#27500A`, 이야기·문화 `#EEEDFE`/`#3C3489`(배경/글자)의 작은 알약이며, 트랙 색은 칩 밖으로 번지지 않는다.
- 글자 성격 (확정): Pretendard(없으면 Noto Sans KR). 각지지도 둥글지도 않은 기본 고딕. 코스 이름 20px 굵게, 스팟 이름 18px 굵게, 본문 15px, 보조 13px, 하단 안내 12px. 굵기는 400과 700 두 단계만 쓴다.
- 모서리·그림자: 카드 12px, 칩 알약(999px), 버튼 8~10px. 그림자는 쓰지 않고 테두리로만 구분한다. 그라데이션은 코스 목록 히어로 블록에만 쓴다.
- 버튼 (확정): 줄 끝의 바깥 링크 "네이버지도에서 열기", "공식 페이지", "네이버플레이스"는 밑줄 글자가 아니라 짙은 청록 `#0F6E56` 채움 + 흰 글자 + 8px 둥근 박스이며 높이 40px 안팎(줄 전체 높이는 44px 이상). 식당 부록의 "근처 식당 네이버지도에서 보기"는 같은 채움에 10px 모서리, 높이 48px, 카드 폭 전체. "← 코스 목록"처럼 화면 안에서 이동하는 링크만 글자 링크로 둔다.
- 화면 느낌 (확정): 여행안내서가 아니라 출발 전 확인용 체크카드. 항목이 메뉴판처럼 줄줄이 보이고, 각 줄 오른쪽 끝에 "공식 페이지", "네이버지도에서 열기" 같은 바깥 링크가 메뉴판의 가격 자리처럼 정렬되어 추가 정보 수집의 출발점이 된다. 감성 사진과 긴 소개 글은 쓰지 않는다.
- 손가락 기준 (확정): 누르는 요소의 높이는 최소 44px. 참고 사이트의 모바일 탭 높이(중앙값 35px, 최소 13px)는 따라 하지 않는다.

## 3 화면별 프롬프트 블록 (Google Stitch 붙여넣기용)

**이 절은 2026-09-16 시안 제작 때 쓴 기록이다. 구현 기준은 4절의 확정 시안 분석과 5절의 디자인 시스템이며, 이 절의 "권역 소개 3줄"과 지도 상자는 2026-09-18 기능 명세 R1에서 구현 범위에서 빠졌다.**

각 블록은 그 자체로 완결된다. Stitch는 이전 블록을 기억하지 못하므로 "스타일" 줄을 매 블록에 반복했다. 스타일 줄은 확정 무드(A + 크림 바탕) 기준이다. 카드 안 예시 문구는 모양을 잡기 위한 것이며 실제 운영 정보는 구현 단계에서 데이터 파일로 넣는다.

#### 시선 흐름과 화면 밀도

- 코스 목록: 히어로 → 요약 목록 → 칩 → 카드 순서로 내려간다. 같은 코스가 요약 목록과 카드에 두 번 나온다.
- 코스 상세: 추천 주차장 띠 → 3분할 탭 → 줄 목록. 줄마다 썸네일이 붙어 캔버스보다 정보 밀도가 높다. 진초록 채움 버튼이 오른쪽 열에 정렬되어 메뉴판식 배치는 유지된다.
- 모바일: PNG 폭이 1280·2390px라 PC 폭으로 그려졌다. 한 열 구조라 390px에서도 같은 순서로 쌓이되, 3분할 탭과 썸네일 줄의 폭 처리는 구현 때 정한다.

#### 캔버스 시안·확정 무드와 다른 점

- 바탕이 흰색이다(확정 무드는 연한 미색 `#FAF7F0`). 상단에 진초록 그라데이션 히어로 블록이 있다(확정 무드는 그라데이션 없음).
- 버튼 색이 캔버스의 `#0F6E56`보다 어두운 진초록으로 보인다. 정확한 값은 미확인.
- 주차 안내·시설 줄에 썸네일 자리, 상시 개방 시설에 "지도 열기" 버튼, 스팟 이름 옆 "★ 추천" 배지, 식당 부록의 "추천 식당" 라벨이 추가됐다.
- 시설 이름이 공식 이름(이천시립박물관, 경기도자미술관)으로 바뀌었고, 운영시간·휴무·문의 전화가 실제 값으로 채워졌다(캔버스는 자리표시였다). 이 값들은 구현 때 데이터 파일에 옮기기 전에 공식 페이지에서 한 번 더 확인한다.

#### PRD와 어긋나거나 없던 요소와 결정 결과 (2026-09-18 학습자 결정)

1. 약도 이미지 구역("방문자 시점 약도, 별도 제작 후 삽입"): **넣는다.** 스팟마다 약도 이미지 1장(선택)을 데이터에 추가하고, 없는 스팟은 구역을 숨긴다. PRD 3·5절에 추가.
2. 바깥 링크 타일 2개(이천시 공식 블로그, 이천관광 누리집): **넣는다.** 코스 목록 맨 아래, 하단 안내 위. PRD 3·4절에 추가.
3. "코스 5개 한눈에" 요약 목록: **넣는다.** 히어로 아래에 코스 이름·트랙 칩·권역·꺾쇠만 있는 5줄. 누르면 코스 카드와 같은 상세로 이동. PRD 4절에 추가.
4. 스팟 카드의 3분할 탭(추천 장소 N / 방문 팁 N / 약도 보기): **넣는다.** 펼친 카드 안에서 세 구역 중 하나를 골라 보는 탭이며, 기본은 "추천 장소". PRD 3·4절에 추가.
5. 권역 소개 3줄: **넣지 않는다.** (2026-09-18 기능 명세 R1에서 뒤집은 결정) 코스 요약 줄과 코스 카드마다 권역 이름이 이미 붙어 있어 같은 말이 세 번 나온다. PRD 4절과 6절을 이에 맞춰 갱신했다.
9. 지도 상자("스팟 5곳 위치"): **넣지 않는다.** (2026-09-18 기능 명세 R1) 네이버지도 임베드의 키 발급 조건이 지났다. 코스 카드 5장 아래에서 바로 바깥 링크 타일 2개로 이어진다. 위치 확인은 스팟 카드의 주차장별 "지도 열기" 버튼이 맡는다.
10. 하단 안내 줄 수: 서비스 한 줄 소개, 기준일 한 줄, "지도 기준" 뜻 한 줄, 모두 3줄이다. (2026-09-18 기능 명세 R1) 시안 `03-하단안내.png`와 같고, PRD에 있던 별도의 "공식 페이지·전화 확인 기준" 줄은 기준일 줄과 같은 말이라 뺐다.
6. 사진: 학습자 결정으로 "Wikimedia Commons" 표기 사진도 유지한다. 직접 촬영분을 우선하고, 없으면 자유 이용 허가(CC) 사진을 출처·저작자·라이선스 표기와 함께 쓴다. PRD 5절 사진 규칙을 이렇게 바꾼다.
7. 이름 변경 확인됨: 이천농업테마공원의 추천 주차장은 "안내센터 옆 주차장", 시설은 "쌀문화전시관". PRD 코스 표를 갱신한다. 이 주차장은 남부 코스 두 개가 함께 쓴다.
8. 무드: 흰 바탕 + 진초록 히어로로 갱신(1절·5절 반영). 미색 바탕은 `--bg` 값 하나로 되돌릴 수 있다.

#### 화면별 구조와 시선 흐름

- 코스 목록: 시선은 서비스 이름 → 권역 소개 → 취향 칩 → 카드의 굵은 코스 이름 → 카드 오른쪽 꺾쇠 순서로 내려간다. 색이 있는 요소는 트랙 칩(3색)과 청록 점만이라 카드 이름이 가장 먼저 읽힌다. 카드는 한 열, 폭 358px(390 − 좌우 16).
- 코스 상세: 접힌 카드에서는 청록 추천 주차장 띠가 가장 먼저 보이고, 펼친 카드에서는 각 줄 오른쪽 끝의 청록 채움 버튼이 세로로 정렬되어 메뉴판의 가격 열처럼 읽힌다. 주차 안내 줄의 화살표 체인은 줄바꿈되어도 화살표가 이어지도록 감싸기 배치를 썼다.

- 모바일 변화: 모든 아트보드가 390px 기준이라 별도 변화가 없다. PC에서는 같은 배치를 폭 640px 이하의 가운데 기둥으로 보여준다.

#### 시안이 PRD와 다르게 정한 것 (2026-09-16 캔버스 기준)

- 코스 목록의 취향 칩 위에 "아이 취향으로 고르기", 카드 위에 "미리 만든 코스 5개" 소제목을 추가했다. PRD에 없는 글자이며 빼도 화면이 성립한다.

- 카드 안 진입 방향·팁·운영시간 문장은 예시 또는 `[확인 후 기입]` 자리표시다. 실제 값은 구현 때 데이터 파일에서 온다.
