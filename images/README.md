# 이미지 폴더 규칙 및 교체 안내

이 폴더는 이천 아이맵 서비스에서 사용하는 모든 사진과 약도를 관리하는 공간입니다.

## 폴더 구성
- `images/spots/`: 각 스팟(장소)의 대표 사진 (5장: 설봉공원, 이천농업테마공원, 이천목재문화체험장, 덕평공룡수목원, 이진상회)
- `images/thumbs/`: 주차장 및 세부 시설 안내용 작은 썸네일 사진 (약 15장)
- `images/maps/`: 방문자 시점의 약도 이미지 (입구 진입 방향 및 주요 시설 배치)

## 이미지 교체 방법
1. 교체하고 싶은 사진 파일을 동일한 파일명으로 해당 폴더에 덮어쓰기만 하면 화면에 즉시 반영됩니다.
2. 만약 새 파일명을 사용할 경우, `data/spots.json`에서 해당 장소의 `photo.file` 또는 `thumb` 값을 새 파일명으로 변경하시면 됩니다.

## 이미지 생성 및 수집 원칙
- 디자인 시안에서 이미지가 비어 있거나 확보되지 않은 항목은 공식 홈페이지, 웹 검색, 공공누리(KOGL)/위키미디어 등에서 시드 이미지를 참조하여 알맞게 생성/보정하여 배치합니다.
- 모든 이미지는 출처, 저작자, 라이선스를 `data/spots.json`에 명시합니다.
