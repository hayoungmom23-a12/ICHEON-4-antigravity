# 안티그래비티 구현 지시문 · 이천 아이맵

아래 문단을 그대로 복사해 안티그래비티에 붙여넣으세요.

---

이천 아이맵 웹페이지를 구현한다. 디자인 기준은 `handoff/icheon-imap.html` 파일 하나다. 이 파일은 프레임워크 없는 정적 시안이며, 브라우저로 열면 최종 확정 디자인이 그대로 보인다. 색·글자 크기·간격·모서리·버튼 크기·줄바꿈 규칙을 이 파일에서 그대로 읽어 쓴다. 눈대중으로 다시 만들지 말고 값을 복사한다.

텍스트 데이터는 `handoff/courses.js` 한 파일에만 있다(`window.ICHEON_DATA`). 코스 5개와 스팟 5곳, 시설·주차장·팁·식당 정보가 모두 여기 있다. 화면 코드에 문구를 하드코딩하지 않고 이 데이터에서 읽는다. 문구를 고칠 일이 생기면 이 파일만 고친다.

화면은 2개다. 코스 목록(`#/`)과 코스 상세(`#/course/<코스 id>`). 하단 안내는 두 화면 공통으로 맨 아래에 붙는다.

반드시 지킬 것:

- 페이지 바탕은 크림 `#FAF7F0`이다. 흰색이 아니다.
- 히어로는 설봉호 **사진** 위에 검정 그라데이션(위 투명 → 아래 68%)을 덮고 흰 글자를 아래쪽에 둔다. 진초록 그라데이션 블록이 아니다.
- 스팟 카드의 알약 버튼 4개(추천 장소 N / 방문 팁 N / 약도 보기 / 숙박 안내)는 **탭이 아니다.** 누르면 카드가 펼쳐지고 해당 구역으로 스크롤하며, 그 구역 배경이 옅은 청록으로 1.8초 깜박인 뒤 사라진다. 구역들은 동시에 다 보인다.
- 강조색은 진청록 `#0F6E56` 하나, 눌렀을 때 `#085041`. 바깥 링크는 전부 이 색으로 채운 버튼이고 새 창으로 열린다.
- 전화번호는 `white-space: nowrap`으로 묶어 중간에서 끊기지 않게 한다. 본문 전체에 `word-break: keep-all`과 `text-wrap: pretty`를 쓴다.
- 누르는 요소 최소 높이 44px. 줄 버튼 40px(줄 전체 56px), 큰 버튼 48px.
- 사진이 없는 자리는 `#F1EDE4` 상자 + 카메라 선 아이콘으로 둔다. 비워 두거나 구역을 지우지 않는다.
- 지도는 네이버지도를 넣는다. 스크립트 상단 `NAVER_MAP_CLIENT_ID`에 네이버 클라우드 플랫폼 Maps JS API 키를 넣으면 켜지고, 비어 있으면 점선 자리 상자가 보인다. `COORDS`의 좌표 5개는 대략값이므로 네이버지도에서 확인해 교체한다.
- 모바일 우선 한 열, PC에서는 최대 폭 640px 가운데 기둥. PC 전용 격자 배치는 만들지 않는다.

무시할 것:

- `design-prompt.md` 3절(Stitch 프롬프트)과 `design/old/` 폴더는 옛 시안이다.
- `design-prompt.md` 4·5절의 색·크기 값은 2026-09-16 캔버스 기준으로 최종본과 다르다. 배경 설명으로만 읽고, 값이 충돌하면 `icheon-imap.html`을 따른다.
- `design/*.png` 3장은 중간 시안 캡처다. 참고용.

## 프롬프트와 어긋나 있던 부분 (참고)

`design-prompt.md` 4·5절은 캔버스 시안 기준이라 다음이 최종본과 다릅니다. 프롬프트를 나중에 갱신할 때 쓰세요.

- 바탕: 프롬프트 `#FFFFFF` → 최종 `#FAF7F0`
- 히어로: 진초록 그라데이션 → 설봉호 사진 + 검정 오버레이, 서비스명 28px
- 3분할 탭 → 알약 버튼 4개 + 점프·하이라이트 동작
- ★추천 배지: 알약 999px → 6px 모서리 태그
- 하단 안내: 12px 3줄 → 첫 줄 15px 굵게 + 12px 2줄
- 프롬프트에 없는 것: 숙박 안내 구역, 주차 주의 블록, 시설 더보기 펼침, 추천 식당 별 배지(`#FFF3C4`/`#7A4E08`), 전화번호 nowrap 규칙
